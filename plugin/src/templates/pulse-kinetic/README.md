# Pulse Kinetic

Portable customer design reconstructed from the supplied Pulse Kinetic bundled HTML.

The package contains the exact supplied photography and Latin webfont subsets, dedicated shell blocks, editable section variants, and home/contact/privacy content. The reference contact controls are visual only and have no submission endpoint; connect them to the approved customer form integration before production handoff.

Build with `npm run package -- pulse-kinetic`, install the generated theme and plugin on a clean WordPress site, then import its content ZIP through Foundations Delivery.
