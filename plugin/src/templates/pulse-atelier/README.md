# Pulse Atelier

Portable customer block theme generated from the supplied Pulse Atelier standalone design.

The package owns its blocks, fonts, images, theme tokens, shell parts and three-page content bundle. It does not register blocks in the Foundations marketing plugin and does not depend on the legacy Foundations theme. Header, footer and contact details read from Site Settings. Home sections remain individually editable in Gutenberg.

The newsletter and contact controls reproduce the supplied visual design but have no submission endpoint. Connect them to the approved customer form integration before a production handoff.

Build with `npm run package -- pulse-atelier`, install the generated theme and plugin on a clean WordPress site, then import its content ZIP through Foundations Delivery.
