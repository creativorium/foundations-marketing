These Latin font files were extracted from the user-supplied
`doc/client-html/theme/Halo Template (standalone) (2).html` for visual parity.
Instrument Serif supplies display text (regular and italic); Schibsted Grotesk
supplies body text, as one variable file covering the 300-600 range the canvas uses.
Vite includes the files in the scoped customer CSS, without third-party requests.
Only the Latin subsets are bundled — the copy is English, and the extended ranges
are most of the weight.
